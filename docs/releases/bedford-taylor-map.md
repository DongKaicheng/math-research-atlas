# Bedford–Taylor research map

Publication date: 18 November 2026 (Asia/Shanghai).

Atlas project revision: 2. Mathematical source edition: v1.0.1.

## Change

Added a separate current Research map page at
`/projects/bedford-taylor/map/`, a Research map item in the project navigation,
and a direct entry in the project homepage. The page is included in unified
search and the sitemap.

Eight branches organize 34 reading nodes: 14 known-result groups, five model
groups, five obstruction groups and ten open-direction groups. They cover all
74 thematic records and all 14 formal open programme items. Every record and
formal open item has exactly one primary branch; nodes may cross-reference
related branches. All 26 definition groups have links. These group counts
describe navigation and do not count new mathematical theorems.

The page uses a nested text tree with native disclosure controls, a branch
index, direct statement and source links, and expandable complete record lists.
The full tree remains usable without JavaScript. Optional controls expand or
collapse all branches. The layout becomes a vertical reading view on narrow
screens, and status distinctions use text as well as colour.

## Mathematical and publication scope

The tree expresses thematic reading order. Its short summaries preserve the
scope of the linked source statements. Editorial review restored the actual
analytic zero-relation premise in the low-rank quadratic summary, and retained
the model, background, domain and tail qualifications in the affected nodes.
No source status or proof-acceptance status changes. The 14 formal programme
items remain open. Existing frozen editions, paper sources and PDFs are
unchanged.

Record titles, source status labels, formal statement links and permanent IDs
are joined from the v1.0.1 data. The build requires the map's edition to match
the selected source and rejects lost or duplicated primary records. This
prevents an old map from silently surviving a new mathematical publication.

Map feedback uses the existing shared board, with the actual current map URL
and selected edition. Branch hashes remain page context and are not converted
into theorem IDs. The page retains the unsigned publication policy.

The previous Atlas bundle is preserved as revision 1. Git records map and
layout changes; the existing immutable reading editions retain their exact
source and PDF history. The maintainer protocol now describes map updates.

## Verification

The map-specific checks cover all source IDs and statuses, summary fidelity,
local links and anchors, discoverability, real feedback context and unsigned
content. After preserving the concurrent Beilinson–Bloch research-map update,
the complete 67-test repository suite, both immutable-release checks and the
append-only history check passed.
Desktop (1348 px) and mobile (390 px frame) browser review verified readable
text, no horizontal overflow, branch jumps, keyboard disclosure, complete
record lists and direct result navigation. Representative views are retained
in `docs/screenshots/bedford-taylor-map-desktop.jpg` and
`docs/screenshots/bedford-taylor-map-mobile.jpg`.
