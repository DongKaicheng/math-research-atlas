\begin{proposition}[Conditional scalar reduction; F8RC-R]
\label{prop:conditional}
Under H1--H3, for an ordinary compact analytic-interior test satisfying
the representation and Green-symmetry scope above, R-GREEN implies
\[
       L_f(\dd\eta_1)=\int_D\eta.
\]
If smooth double integration by parts is available for the complementary
ordinary test \(\eta_2=\eta-\eta_1\), then
\(L_f(\dd\eta)=\int_D\eta\). Identification with the project Cartier
current, global finite-chart gluing, and extension to the full test class
require their own stated comparison interfaces.
\end{proposition}
