Global skeletons in characteristic zero

4 Analytic curves and skeleta

Open in the English reader · PDF page 706

Statement · exact TeX
\begin{corollary}[\bi{Global skeletons in characteristic zero}
{特征零下的全局骨架}]
\label{cand:charzerosplitmodelskeleton}
\bi{Assume $\operatorname{char}K=0$. In
Theorem~\ref{cand:splitmodelskeleton}, the hypothesis that
the smooth closed points have separable residue fields
can be omitted. The same conclusion holds for the
branch-star correspondence of
Theorem~\ref{cand:residualbranchstar}. Equivariant
homotopies of such models descend under the finite Galois
hypotheses of Corollary~\ref{cand:galoissplitmodelskeleton}.}
{假设 $\operatorname{char}K=0$。在
Theorem~\ref{cand:splitmodelskeleton} 中，可去掉
光滑闭点剩余域可分的假设。
Theorem~\ref{cand:residualbranchstar} 的分支星形
对应也仍成立。这些模型的等变同伦在
Corollary~\ref{cand:galoissplitmodelskeleton} 的
有限 Galois 假设下可以下降。}
\end{corollary}
Full selected proof · exact TeX
\begin{proof}
\bi{The proof of Proposition~\ref{cand:compactcomponentstars}
uses separability only to obtain the completed smooth-tube
contractions. Replace that input by
Theorem~\ref{cand:charzerosmoothtube}. The cofinite
whole-tube estimate is unchanged, so its proof gives the
same compact stars and uniform continuity in time.
Finite closed pasting then proves the global skeleton
theorem with the same nodal intervals and edge lengths.
For branch stars, replace the connected collar input by
the same theorem; every topological argument and every
normalization label is unchanged. Model functoriality
makes the homotopy equivariant, so
Corollary~\ref{cand:galoisretractiondescent} descends it.
The finite-graph quotient argument is purely topological
and again applies without change.}
{Proposition~\ref{cand:compactcomponentstars} 的证明
仅在获得完备光滑管域的收缩时使用可分性。将该输入
换为 Theorem~\ref{cand:charzerosmoothtube}。
余有限完整管域估计不变，因此其证明给出同样的紧
星形空间及对时间参数的一致连续性。有限闭粘合便
证明全局骨架定理，结点区间及边长完全相同。对于
分支星形邻域，同样用上述定理替换连通领形域输入，
其余拓扑论证及正规化标记均不变。模型函子性使
同伦等变，再由 Corollary~\ref{cand:galoisretractiondescent}
下降。有限图商空间的论证纯属拓扑，也原样适用。}
\end{proof}
