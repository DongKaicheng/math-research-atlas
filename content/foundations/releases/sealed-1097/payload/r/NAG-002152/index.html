Genus-zero retraction over the original field

4 Analytic curves and skeleta

Statement · exact TeX
\begin{corollary}[\bi{Genus-zero retraction over the original field}
{原基域上的亏格零收缩}]
\label{cand:genuszerooriginalretraction}
\leavevmode\par
\bi{For $K,C,D$ as in
Theorem~\ref{cand:genuszerogaloismodel},
$(C\setminus D)^{\an}$ admits a jointly continuous
strong deformation retraction onto a finite metric graph
with one infinite ray for each closed point of $D$.
If $D$ is empty, the image can be a single point.
All metrics use the original absolute value on $K$.}
{设 $K,C,D$ 如
Theorem~\ref{cand:genuszerogaloismodel}。
则 $(C\setminus D)^{\an}$ 具有到有限度量图的
联合连续强形变收缩，
对 $D$ 的每个闭点恰有一条无限射线。
若 $D$ 为空，收缩像可取为一个点。
全部度量均使用 $K$ 上的原绝对值。}
\end{corollary}
Full selected proof · exact TeX
\begin{proof}
\bi{Apply Theorem~\ref{cand:generalmarkedmodelskeleton}
to the Galois-compatible marked model just constructed.
Its smooth residual tubes are covered by
Corollary~\ref{cand:charzerosplitmodelskeleton},
including imperfect residue fields.
The entire homotopy is equivariant, so
Corollary~\ref{cand:galoisretractiondescent} descends it.
The finite metric quotient and the ray-orbit calculation
are those already established in
Corollary~\ref{cand:puncturedcurvedvrretraction}.
When $D$ is empty no marked refinement is needed:
the good model $\mathbf P^1_{M^\circ}$ has its single
fixed Gauss vertex as skeleton.}
{对刚构造的 Galois 相容标记模型应用
Theorem~\ref{cand:generalmarkedmodelskeleton}。
其光滑剩余管域由
Corollary~\ref{cand:charzerosplitmodelskeleton}
处理，包括不完美剩余域。
整个同伦等变，故可由
Corollary~\ref{cand:galoisretractiondescent} 下降。
有限度量商及射线轨道的计算，
就是 Corollary~\ref{cand:puncturedcurvedvrretraction}
中已建立的计算。
若 $D$ 为空，无需标记细化；
良好模型 $\mathbf P^1_{M^\circ}$ 的骨架
只有它的固定 Gauss 顶点。}
\end{proof}
