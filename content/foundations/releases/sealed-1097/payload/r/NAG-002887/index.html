\begin{proposition}[Inherited boundary and radial trace functionals; F8AG-A]
\label{prop:ends}
One has
\begin{equation}\label{eq:boundarycontainment}
 \partial_KA\subset (A\cap\partial_KV)\cup E_a\cup E_b.
\end{equation}
Equality is not asserted: a level set can contain points where the
inequality is locally redundant. If an ordinary
\(\beta\in\cA^{n-1,n}(A)\) vanishes near \(A\cap\partial_KV\),
choose smooth real functions \(\psi_a,\psi_b\) equal to one near
the respective endpoint and zero near the other, with disjoint small
endpoint collars. Then
\[
 T_a(\beta)=\BB_A(\psi_a(x)\beta),\qquad
 T_b(\beta)=\BB_A(\psi_b(x)\beta)
\]
are independent of these choices, and
\begin{equation}\label{eq:twotraces}
                         \BB_A(\beta)=T_a(\beta)+T_b(\beta).
\end{equation}
They depend only on the actual germs at the indicated end, within
this inherited-boundary-vanishing class. Without that vanishing
hypothesis, only the full trace is being declared intrinsic here;
one must retain the other boundary contribution for a chosen splitting.
\end{proposition}
