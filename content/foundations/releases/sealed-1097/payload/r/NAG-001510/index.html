Preserving a strict quotient-norm bound

2 Analytic spaces, morphisms and fibres

Open in the English reader · PDF page 222

Statement · exact TeX
\begin{lemma}[\bi{Preserving a strict quotient-norm bound}{保持严格的商范数界}]\label{fnd:quotientradiuscontinuity}
\leavevmode\par
\bi{Let $R$ be strict norm-admissible, let $r_0<r_1$ belong to $\Gamma_K^{\mathrm{div}}$, and let $T=(T_1,\ldots,T_s)$. For each $r\in\Gamma_K^{\mathrm{div}}\cap[r_0,r_1]$, put $E_r=R\{r^{-1}T\}$. Fix polynomials $H_1,\ldots,H_q\in R[T]$, let $J_r=(H_1,\ldots,H_q)E_r$, and give $Q_r=E_r/J_r$ its actual quotient norm. If finitely many $F_1,\ldots,F_n\in E_{r_1}$ satisfy $\|[F_i]\|_{Q_{r_0}}<1$, then there is a real number $r_2$ with $r_0<r_2\leq r_1$ such that}
{设 $R$ 为 strict norm-admissible，$r_0<r_1$ 属于 $\Gamma_K^{\mathrm{div}}$，且 $T=(T_1,\ldots,T_s)$。对每个 $r\in\Gamma_K^{\mathrm{div}}\cap[r_0,r_1]$，记 $E_r=R\{r^{-1}T\}$。固定多项式 $H_1,\ldots,H_q\in R[T]$，令 $J_r=(H_1,\ldots,H_q)E_r$，并给 $Q_r=E_r/J_r$ 配备实际商范数。若有限多个 $F_1,\ldots,F_n\in E_{r_1}$ 满足 $\|[F_i]\|_{Q_{r_0}}<1$，则存在实数 $r_2$，满足 $r_0<r_2\leq r_1$，且}
\[
 \|[F_i]\|_{Q_r}<1
 \quad\text{for all }i
 \text{ and }r\in\Gamma_K^{\mathrm{div}}\cap[r_0,r_2].
\]
\end{lemma}
Full selected proof · exact TeX
\begin{proof}
\bi{All the ideals in the statement are actual closed ideals by Lemma~\ref{fnd:radicalradiusaffinoid}. For each $i$, the quotient-norm inequality gives $j_i\in J_{r_0}$ with $\|F_i+j_i\|_{r_0}<1$. Write $j_i=\sum_\nu u_{i\nu}H_\nu$, where $u_{i\nu}\in E_{r_0}$. Approximate the finitely many $u_{i\nu}$ by polynomials $v_{i\nu}\in R[T]$ closely enough that}
{由 Lemma~\ref{fnd:radicalradiusaffinoid}，陈述中的各理想均为实际闭理想。对每个 $i$，商范数不等式给出 $j_i\in J_{r_0}$，使 $\|F_i+j_i\|_{r_0}<1$。写 $j_i=\sum_\nu u_{i\nu}H_\nu$，其中 $u_{i\nu}\in E_{r_0}$。用多项式 $v_{i\nu}\in R[T]$ 充分逼近这有限多个 $u_{i\nu}$，使}
\[
 G_i=F_i+\sum_\nu v_{i\nu}H_\nu\in E_{r_1},
 \qquad \|G_i\|_{r_0}<1.
\]
\bi{This step uses an expression in the actual finitely generated ideal, rather than merely membership in a closure. It does not require a norm-minimizing representative. Choose $\theta<1$ strictly larger than every $\|G_i\|_{r_0}$. Write $G_i=\sum_\alpha a_{i\alpha}T^\alpha$. Since $G_i\in E_{r_1}$, outside a finite set of indices one has $\|a_{i\alpha}\|r_1^{|\alpha|}<\theta$, simultaneously for all $i$. Those coefficients satisfy the same bound for every $r\leq r_1$. For each of the finitely many remaining indices, the real function $r\mapsto\|a_{i\alpha}\|r^{|\alpha|}$ is continuous and is strictly less than $\theta$ at $r_0$. Hence it remains less than $\theta$ on some common interval $[r_0,r_2]$ with $r_2>r_0$. Shrink $r_2$ to at most $r_1$. Then $\|G_i\|_r\leq\theta<1$ throughout this interval. Since $G_i-F_i\in J_r$, the same strict bound holds in $Q_r$. An empty list of elements requires no estimate.}
{此处使用的是实际有限生成理想中的表达式，而不只是属于某个闭包，也无须存在范数达到下确界的代表元。选择 $\theta<1$，严格大于所有 $\|G_i\|_{r_0}$。写 $G_i=\sum_\alpha a_{i\alpha}T^\alpha$。由于 $G_i\in E_{r_1}$，在某个有限指标集之外，对所有 $i$ 同时有 $\|a_{i\alpha}\|r_1^{|\alpha|}<\theta$；故这些系数对每个 $r\leq r_1$ 仍满足同一界。对余下有限多个指标，实函数 $r\mapsto\|a_{i\alpha}\|r^{|\alpha|}$ 连续，且在 $r_0$ 处严格小于 $\theta$。因此它们在某个共同区间 $[r_0,r_2]$ 上仍小于 $\theta$，其中 $r_2>r_0$。将 $r_2$ 缩小到不超过 $r_1$，即得整个区间上 $\|G_i\|_r\leq\theta<1$。又因 $G_i-F_i\in J_r$，同一严格界在 $Q_r$ 中成立。元素列为空时无须估计。}
\end{proof}
