Remaining historical proof gap

Selected results establish the residual degree and Gauss points, but not equality with the actual mixed model measure at the original field scope, including transported coordinates.

Historical statement · exact TeX
\begin{proposition}[Same radial data, different model measures]
\label{f9fm:modelambiguity}
In every dimension $d\geq2$ and for the same $L_i$ as above, there are
two collections of semipositive algebraic model metrics whose mixed
Chambert--Loir measures $\mu_0,\mu_1$ satisfy
\[
 \bar t_*\mu_0=\bar t_*\mu_1=D\delta_0,\qquad
 \mu_0(X^\an)=\mu_1(X^\an)=D,\qquad\mu_0\ne\mu_1.
\]
The first collection is toric for the specified $T$-coordinates; the
second is a translated product model and is not toric for those
coordinates. Thus this is not a counterexample within the fixed toric
metric class or within the positive smooth-density hypotheses of
Theorem~\ref{f9fm:radondetermination}.

Moreover, if positivity is dropped, even the smooth radial data $Wdt$
does not determine a signed Radon measure: one may add a nonzero signed
measure of zero tropical pushforward to $\mu_\Gamma$.
\end{proposition}
