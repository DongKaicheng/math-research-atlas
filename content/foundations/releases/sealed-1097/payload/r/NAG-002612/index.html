The ramified coefficient map is not a torsor map

Proper direct image on historical ordinary compact tests

Statement · exact TeX
\begin{lemma}[The ramified coefficient map is not a torsor map]
\label{cand:f5tame:ramifiedtensor}
In (5), consider the natural map
\[
 \theta:R'\otimes_RR'\longrightarrow\prod_{j=0}^{e-1}R',
 \qquad a\otimes b\longmapsto(a\sigma^j(b))_j .
 \tag{6}
\]
It is injective. In Fourier coordinates its image is
\(\bigoplus_{i=0}^{e-1}s^iR'\), so
\[
 \operatorname{coker}(\theta)\simeq
       \bigoplus_{i=1}^{e-1}R'/(s^i),\qquad
 \operatorname{length}_{R'}\operatorname{coker}(\theta)
       =e(e-1)/2 .
 \tag{7}
\]
In particular (6) is not an isomorphism.
\end{lemma}
Full selected proof · exact TeX
\begin{proof}
Using \(u=1\otimes s\), the source is
\(R'[u]/(u^e-s^e)\), free over \(R'\) on \(1,u,\ldots,u^{e-1}\).
The column for \(u^i\) in (6) is
\(s^i(\zeta^{ji})_{j=0}^{e-1}\). The Fourier matrix
\((\zeta^{ji})\) is invertible over \(R'\), with inverse given
by \(e^{-1}(\zeta^{-ij})\). Thus (6) is equivalent to the diagonal
map with entries \(1,s,\ldots,s^{e-1}\). These are nonzero in
the DVR \(R'\), proving all assertions.
\end{proof}
