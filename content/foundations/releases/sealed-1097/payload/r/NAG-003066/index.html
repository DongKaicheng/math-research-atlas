The universal GK kernel restricted to smooth forms

Proper direct image on historical ordinary compact tests

Open in the English reader · PDF page 1853

Statement · exact TeX
\begin{lemma}[The universal GK kernel restricted to smooth forms]\label{lem:gk}
Fix an original GK tropical chart $(V,\varphi_U)$, with tropical image $P$ in a real open set $\widetilde\Omega$. Assume the canonical cycles of this chart and each compatible test chart have their actual tropical supports, finite pure polyhedral structures and strictly positive top-dimensional weights. Let $\mathcal N$ be GK's kernel from Definition~4.4, testing every compatible algebraic morphism and chart. For an ambient smooth $(p,q)$-form $\alpha$,
\[
  \alpha\in\mathcal N
       \quad\Longleftrightarrow\quad
  \alpha\text{ is tangentially zero on every face of }P.
\]
This equality is independent of the numerical values of the positive weights.
\end{lemma}
Full selected proof · exact TeX
\begin{proof}
For the reverse implication, take any compatible algebraic morphism and chart. Its integral affine map $F$ carries its actual tropical image into $P$. Subdivide so that each source cell maps into a target cell. The differential of $F$ maps the source tangent into the target tangent; hence $F^*\alpha$ is tangentially zero. Its product with the integration current of the source tropical cycle is zero, which is exactly the smooth instance of restriction in GK~\cite[3.4 and 4.4]{GK}. This proves membership in every test kernel, including rank-dropping maps and maps whose source dimension differs from that of $U$.

Conversely, the identity morphism is one of the tests. It says $\alpha\wedge\delta_P=0$. If a tangential coefficient of $\alpha$ were nonzero in the relative interior of a maximal cell, choose a small ball meeting no other maximal cell and a complementary constant superform which isolates that coefficient. Multiplication by a nonnegative smooth bump supported in the ball gives a nonzero pairing, because the coefficient has fixed sign on a smaller ball and the weight is positive. Thus all coefficients vanish in every maximal relative interior. Continuity and purity give vanishing on every face. If $p$ or $q$ exceeds the cell dimension, the tangential restriction is already zero by exterior degree. The zero-dimensional case is the same assertion for functions on a finite set.
\end{proof}
