A finite vertical module with zero closed fibre vanishes

Proper direct image on historical ordinary compact tests

Statement · exact TeX
\begin{lemma}[A finite vertical module with zero closed fibre vanishes]
\label{cand:f5res:finiteverticalmodule}
Let \(R\) be a valuation ring of a nontrivially real-valued field \(F\),
with maximal ideal \(\mathfrak n\). Let \(S\) be any \(R\)-algebra,
and let \(C\) be a finitely generated \(S\)-module. If
\[
             C\otimes_R F=0,\qquad C=\mathfrak n C,
 \tag{1}
\]
then \(C=0\). Neither \(S\) nor \(R\) is required to be Noetherian.
\end{lemma}
Full selected proof · exact TeX
\begin{proof}
Choose finitely many \(S\)-module generators \(c_1,\ldots,c_q\).
The generic vanishing means that each \(c_j\) is annihilated by
some nonzero \(a_j\in R\). The product
\(a=\prod_j a_j\ne0\) therefore annihilates all of \(C\).
If there are no generators, or \(a\) is a unit, the assertion follows.

For each \(j\), write \(c_j\) as a finite sum
\[
                c_j=\sum_\ell \beta_{j\ell}d_{j\ell},
       \qquad \beta_{j\ell}\in\mathfrak n,\quad d_{j\ell}\in C .
\]
If every coefficient in these finitely many expressions is zero,
then \(C=0\). Otherwise choose a nonzero coefficient \(\lambda\)
having least valuation among this \emph{finite} list.
Every \(\beta_{j\ell}/\lambda\) belongs to \(R\), so
\(c_j\in\lambda C\) for all \(j\). Since these elements generate
over \(S\), this proves \(C=\lambda C\), with \(v(\lambda)>0\).

Rank one now supplies an integer \(N\geq1\) with
\(Nv(\lambda)\geq v(a)\). Thus \(\lambda^N/a\in R\).
Iteration gives
\[
           C=\lambda^N C
             =(\lambda^N/a)\,aC=0 .
\]
Only a finite list of coefficients was minimized. No least positive
element of \(v(F^\times)\), and no generator of \(\mathfrak n\),
was used.
\end{proof}
