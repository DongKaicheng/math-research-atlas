Comparing tests for strict presentations

2 Analytic spaces, morphisms and fibres

Open in the English reader · PDF page 368

Statement · exact TeX
\begin{corollary}[\bi{Comparing tests for strict presentations}{Strict 表示的测试比较}]
\label{fnd:stricttestgeneralizedequivalence}
\bi{Suppose $A,B$ are strict norm-admissible $K$-affinoid algebras, with trivial valuation on $K$ allowed. A bounded map $A\to B$ is a strict-test affinoid-domain presentation if and only if it is a generalized same-$K$ affinoid-domain presentation, and if and only if it has the affinoid-domain property for all complete-extension affinoid tests. The represented subset and algebra are unchanged.}
{设 $A,B$ 为 strict norm-admissible $K$-affinoid 代数，允许 $K$ 的赋值平凡。有界映射 $A\to B$ 是 strict-test affinoid 域表示，当且仅当它是同一 $K$ 上的 generalized affinoid 域表示，也当且仅当它具有关于全部完备扩域 affinoid 测试的域泛性质。所表示的子集与代数均不改变。}
\end{corollary}
Full selected proof · exact TeX
\begin{proof}
\bi{Only the implication from strict tests to all complete-extension tests requires proof. Let $U$ be the represented subset. Corollary~\ref{fnd:strictdomainrationalbasis} gives a finite covering $U=\bigcup_iR_i$ by original-$A$ rational domains with unit-radius presentations. Lemma~\ref{fnd:rationalrestrictiondomainbridge} identifies each $A_{R_i}$ and each intersection algebra as an actual rational quotient of $B$. Thus we have exactly the rational-cover data used in the proof of Theorem~\ref{fnd:generalizeddomainextensiontests}, without first enlarging the test class. For a bounded $A\to C$ into any complete-extension affinoid whose spectral image lies in $U$, pull back these tuples. The rational universal property gives $A_{R_i}\to C_i$ and the maps on their overlaps. Their composites from $B$ match. The norm-strict rational Tate equalizer glues them to a bounded $B\to C$. Any other factorization has the same restrictions, by uniqueness for the actual rational quotients of $B$; injectivity of the equalizer therefore gives equality. This proves the implication. The other implications restrict the test class.}
{只需证明从 strict 测试到全部完备扩域测试的方向。令 $U$ 为所表示的子集。Corollary~\ref{fnd:strictdomainrationalbasis} 给出有限覆盖 $U=\bigcup_iR_i$，其中各 $R_i$ 都具有原 $A$ 上的单位半径 rational 表示。由 Lemma~\ref{fnd:rationalrestrictiondomainbridge}，各 $A_{R_i}$ 及其交叠代数都识别为 $B$ 的实际 rational 商。因此，在尚未扩大测试类之前，已经取得 Theorem~\ref{fnd:generalizeddomainextensiontests} 的证明中使用的全部 rational 覆盖数据。对谱像包含于 $U$ 的有界映射 $A\to C$，其中 $C$ 是任一完备扩域上的 affinoid，拉回这些 tuples。Rational 泛性质给出 $A_{R_i}\to C_i$ 及其交叠上的映射，复合后从 $B$ 出发的映射彼此匹配。Norm-strict rational Tate 等化子将它们粘合为有界映射 $B\to C$。对任一其他分解，$B$ 的实际 rational 商的唯一性保证其限制相同，再由等化子的单射性得到整体相等。这就证明所需方向；其余方向仅需缩小测试类。}
\end{proof}
