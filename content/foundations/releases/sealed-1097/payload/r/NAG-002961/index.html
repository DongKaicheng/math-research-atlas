\begin{proposition}[No threshold uniform over all compact tests; F8SA-U]
\label{prop:nonuniform}
Let \(X=\mathbb A_K^{1,\mathrm{an}}\), \(f=T\), and
\(K_0=\{|T|\leq1\}\Subset\Int(X/K)\). Choose
\(\varphi\in C_c^\infty((-1/4,1/4))\) with \(\varphi(0)=1\).
For each integer \(m\geq1\), the scalar test
\(\eta_m=\varphi(\log|T|+m)\), extended by zero, is an ordinary
smooth compact test supported in \(K_0\). Nevertheless,
\[
 L_T(\dd\eta_m)=0,
 \qquad
 \int_X\max(\log|T|,-m)\,\dd\eta_m=1.
\]
Thus no one logarithmic threshold works for every such test, even with
this common compact support constraint.
\end{proposition}
