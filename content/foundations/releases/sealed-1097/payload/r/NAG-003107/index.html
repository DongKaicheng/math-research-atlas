Historical statement · exact TeX
\begin{proposition}[Finite strong-dual transfer; F8NM-S]\label{prop:strong}
Suppose \(V=\cM(A)\) is pure of dimension \(n\),
\(U\subseteq\Int(V/K)\) is ordinary open, and
\(j_i:U_i\hookrightarrow U\) are its finitely many restricted reduced
components with the original weights \(m_i\).
Let \(T_{M,i},T_i\) be continuous functionals on the corresponding
native test spaces, and define
\(D_M=\sum_i m_i(j_i)_*(T_{M,i}-T_i)\).
For every \(\tau_a\)-bounded set \(B\),
\begin{equation}\label{eq:strong}
 \sup_{\alpha\in B}|D_M(\alpha)|
 \leq\sum_i m_i\sup_{\beta\in j_i^*B}|(T_{M,i}-T_i)(\beta)|.
\end{equation}
Thus component strong convergence implies ambient strong convergence.
Uniform eventual equality on each component bounded set also transfers.

For a globally represented ambient regular quotient \(f=a/b\) on
\(U\), the native logarithmic pairings and the smooth truncations
\(u_M=\ell_M(a)-\ell_M(b)\) have exactly this decomposition, with
\(D_M=T_{f,M}-L_f\). The conclusion is conditional on the component
strong-convergence premise in the stated topology.
\end{proposition}
