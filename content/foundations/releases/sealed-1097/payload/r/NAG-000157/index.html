Historical statement · exact TeX
\begin{theorem}\label{fnd:boundaryfacts}
\bi{Relative interior is open and behaves locally on the base under analytic-domain covers. If $V\subset X$ is an analytic domain, $\operatorname{Int}(V/X)$ equals its ordinary topological interior in $X$. An affinoid morphism $\mathcal M(B)\to\mathcal M(A)$ is boundaryless if and only if $A\to B$ is finite and admissible. Finite morphisms are stable under base change.}
{Relative interior 为 open，并在 base 的 analytic-domain covers 下具有 local 性质。若 $V\subset X$ 是 analytic domain，则 $\operatorname{Int}(V/X)$ 等于 $V$ 在 $X$ 中的 ordinary topological interior。Affinoid morphism $\mathcal M(B)\to\mathcal M(A)$ 为 boundaryless 当且仅当 $A\to B$ 是 finite 且 admissible。Finite morphisms 在 base change 下保持。}
\end{theorem}
