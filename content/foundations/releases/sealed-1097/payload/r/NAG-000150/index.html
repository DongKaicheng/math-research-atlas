Result 4.3.1

4 Analytic curves and skeleta

Open in the English reader · PDF page 630

Statement · exact TeX
\begin{proposition}\label{fnd:annulusretraction}
\bi{The map $\tau(x)=\zeta_{0,|T(x)|}$ is a continuous retraction onto $\Sigma$. There is a strong deformation retraction from the identity to $\tau$ which preserves $|T|$.}
{Map $\tau(x)=\zeta_{0,|T(x)|}$ 是到 $\Sigma$ 的 continuous retraction。存在从 identity 到 $\tau$ 的 strong deformation retraction，并保持 $|T|$。}
\end{proposition}
Full selected proof · exact TeX
\begin{proof}
\bi{Write $P(X+Z)=\sum_jP_j(X)Z^j$ for a polynomial, using its Taylor coefficients without division by factorials. For $u\in[0,1]$, define a seminorm by}
{对 polynomial 写出 $P(X+Z)=\sum_jP_j(X)Z^j$，使用不除以 factorials 的 Taylor coefficients。对 $u\in[0,1]$，定义 seminorm}
\[
 |P|_{H(x,u)}=\max_j |P_j(x)|\,(u|T(x)|)^j.
\]
\bi{This is evaluation at $T(x)+Z$ followed by the Gauss norm of radius $u|T(x)|$ over $\mathcal H(x)$, hence multiplicative. Its value on $T$ is $|T(x)|$, so it defines a point of the same annulus. For $u=0$ it is $x$. For $u=1$, translation by the scalar $T(x)$ preserves the radius-$|T(x)|$ Gauss norm, since this scalar has exactly that size; hence the point is $\zeta_{0,|T(x)|}$.}
{这是先在 $T(x)+Z$ 处 evaluation，再取 $\mathcal H(x)$ 上 radius $u|T(x)|$ 的 Gauss norm，因此为 multiplicative。它在 $T$ 上的 value 为 $|T(x)|$，所以定义同一 annulus 中的 point。当 $u=0$ 时得到 $x$。当 $u=1$ 时，由于 scalar $T(x)$ 的 size 恰为 $|T(x)|$，按此 scalar 的 translation 保持 radius-$|T(x)|$ Gauss norm；因此得到 $\zeta_{0,|T(x)|}$。}

\bi{For a skeletal point $x=\zeta_{0,\rho}$, each Taylor term has size at most $|P|_x$, while the $j=0$ term already has that size. Thus the homotopy fixes $\Sigma$. Finally the displayed formula is continuous in $(x,u)$ for every polynomial. Inversion of $T$ is continuous on the annulus, and Laurent polynomial approximations converge uniformly in its affinoid norm. Therefore all analytic evaluations are continuous along the homotopy. This proves the strong deformation retraction.}
{对 skeletal point $x=\zeta_{0,\rho}$，每个 Taylor term 的 size 都不超过 $|P|_x$，而 $j=0$ 项已经具有该 size，故 homotopy 固定 $\Sigma$。最后，对每个 polynomial，上式关于 $(x,u)$ continuous。$T$ 的 inversion 在 annulus 上 continuous，且 Laurent polynomial approximations 在其 affinoid norm 中 uniformly converge，所以所有 analytic evaluations 沿 homotopy continuous。这就证明 strong deformation retraction。}
\end{proof}
