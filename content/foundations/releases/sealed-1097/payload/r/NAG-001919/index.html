Completion of an algebraic quotient

3 Reduction, formal models and residual geometry

Open in the English reader · PDF page 520

Statement · exact TeX
\begin{lemma}[\bi{Completion of an algebraic quotient}
{代数商的完备化}]
\label{fnd:adicquotientcompletion}
\bi{For a ring $R$ with its $\pi$-adic topology and an ideal
$J\subset R$, the natural map $\widehat R\to\widehat{R/J}$ is
surjective and its kernel is the closure of the image of $J$ in
$\widehat R$. If multiplication by $\pi$ is injective on $R/J$,
it is injective on $\widehat{R/J}$ as well, and}
{对配备 $\pi$-adic 拓扑的环 $R$ 及理想 $J\subset R$，自然映射
$\widehat R\to\widehat{R/J}$ 满射，其核为 $J$ 的像在
$\widehat R$ 中的闭包。若 $\pi$ 在 $R/J$ 上的乘法为单射，
则其在 $\widehat{R/J}$ 上的乘法也为单射，且}
\[
 (R/J)/\pi^n(R/J)\simeq
       \widehat{R/J}/\pi^n\widehat{R/J}\quad(n\geq1).
\]
\end{lemma}
Full selected proof · exact TeX
\begin{proof}
\bi{Lift a compatible system in $R/(J+\pi^nR)$ recursively to
$r_n\in R$. Compatibility allows one to alter $r_{n+1}$ by an
element of $J$ so that $r_{n+1}-r_n\in\pi^nR$. The resulting
Cauchy system defines the required element of $\widehat R$.
An element in the kernel can, modulo every $\pi^n$, be represented
by an element of $J$, which is precisely the asserted closure
condition. Put $C=R/J$. If $\pi x=0$ in $\widehat C$, choose a
representative $c\in C$ of its component modulo $\pi^{n+1}$.
Then $\pi c\in\pi^{n+1}C$; cancellation in $C$ yields
$c\in\pi^nC$. Thus every component of $x$ is zero. Finally a
compatible system vanishing modulo $\pi^n$ can be divided by
$\pi^n$ componentwise, using the same cancellation to verify
compatibility. The kernel of $\widehat C\to C/\pi^nC$ is therefore
$\pi^n\widehat C$, proving the last assertion.}
{将 $R/(J+\pi^nR)$ 中的相容类递归地提升为 $r_n\in R$。
相容性允许用 $J$ 中元素调整 $r_{n+1}$，使
$r_{n+1}-r_n\in\pi^nR$。所得 Cauchy 系统给出
$\widehat R$ 中所需元素。核中的元素对每个 $\pi^n$ 都可由
$J$ 中的元素表示，这恰为所述闭包条件。令 $C=R/J$。
若 $\widehat C$ 中有 $\pi x=0$，选取 $x$ 模 $\pi^{n+1}$
分量的代表 $c\in C$，则 $\pi c\in\pi^{n+1}C$；在 $C$ 中
消去 $\pi$，得到 $c\in\pi^nC$，故 $x$ 的每个分量均为零。
最后，对模 $\pi^n$ 消失的相容系统逐分量除以 $\pi^n$，
同样的消去论证保证其相容性。因此
$\widehat C\to C/\pi^nC$ 的核就是 $\pi^n\widehat C$，
证明最后一个断言。}
\end{proof}
