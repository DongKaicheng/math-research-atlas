# Foundations web edition

This directory contains the English HTML reading projection of `sealed-1097`. The source manuscript was matched to the sealed edition through its compiled PDF SHA-256. The projection uses the English text, mathematical notation, figures and cross-references of that edition. Each Tag retains the coverage status of its permanent record.

`index.json.gz` records the source hash, chapter catalogue, permanent Tag locations and bookmark destinations. The other gzip files contain the ordered HTML blocks, section headings and proof ranges for individual parts, chapters and appendices. The site builder reuses these blocks for Tag statements and proofs. The chapter proof heading links to each matching NAG Tag. A manuscript proof without a matching NAG record receives a web proof permalink scoped to this edition. It carries the author's proof and any matched references from that text. Its identifier records a reading location and does not add a mathematical record to the sealed edition.

The publishing build reads these derived files directly and checks their edition binding and Tag anchors. The fixed edition remains available for citation. The original source package is kept with the project owner.

`../dependency-review.json` records applications checked in the current reading edition, acknowledged external prerequisites, and proof bindings that required editorial review. The statement and proof digests keep those judgments tied to the passages that were actually read. The site uses the sealed dependency register and these checked applications for proof inputs. It shows references extracted from the manuscript as candidates until their logical role and hypotheses have been checked. Stable `FND` reading records give unregistered statements a link derived from their source label.
