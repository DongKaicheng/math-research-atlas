Closed parameter bands and conditional currents

Result summary

Conormal Borel parameter bands give separately closed restrictions and conditional currents on the original analytic space. One exceptional set works for all original tests and refinements, and the qualified band-capacity completion follows.

Hypotheses and scope

The parameter-annihilation, conormal and disintegration hypotheses are retained. Raw-capacity and outer-capacity identifications apply only to the specified bands.
