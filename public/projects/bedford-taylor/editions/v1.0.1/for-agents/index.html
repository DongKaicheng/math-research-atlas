Structured access

Read-only access for research agents

Stable result identities and exact source links make the project reusable without granting an agent permission to modify it.

The JSON endpoints below describe this research edition. Their mathematical status fields preserve the source qualification. Use the formal articles and proof sources for the actual arguments; a search result is a navigation aid.

EndpointContents
/data/project.jsonProject identity, source edition, conventions and access policy
/data/topics.json74 research records with scope and proof destinations
/data/progress-overview.jsonSix reading groups and their complete source-record coverage
/data/definitions.jsonExplicit definitions, article links and usage by open problem
/data/statements.jsonFormal statements and permanent maintainer identities
/data/programme.json14 conjectures, questions and research problems
/data/search-index.jsonSearchable titles, text and stable links
/data/source-manifest.jsonExact selected source files and SHA-256 identifiers
/llms.txtConcise entry points for a reading agent

How to cite or continue a result

  1. Record the research ID and source edition.
  2. Read the scope and exact statement in the linked article or source.
  3. Inspect the complete argument and its cited foundational inputs.
  4. Keep source completion, independent review and publication state separate.
  5. Propose corrections against an exact source hash and retain the previous edition.

This edition exposes reading endpoints only. It provides no public write endpoint and does not configure unattended updates. The current site audience also applies to these files.
