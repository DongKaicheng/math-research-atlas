Arithmetic Lefschetz and Integral Heights

Statement

For the pointed product and anchored polarization in BB-CENTRAL-DATA, over each fixed finite E/FE/FE/F, off-central vanishing on every subproduct is equivalent to the isomorphisms

ℓn+1−2r:Vr(XE)→∼Vn+1−r(XE),1≤r≤⌊(n+1)/2⌋. \ell^{n+1-2r}:V^r(X_E)\xrightarrow{\sim}V^{n+1-r}(X_E),\qquad 1\le r\le\lfloor(n+1)/2\rfloor. ℓn+1−2r:Vr(XE​)∼​Vn+1−r(XE​),1≤r≤⌊(n+1)/2⌋.

The statement is an equivalence of properties; it does not assume either side has been established for a general product.

Argument

The curve projectors give the exact decomposition

V∗(XE)=⨁S,cUSc(E)⊗BI[c],BI=Q[xi:i∈I]/(xi2),I=[n]∖S. V^*(X_E)=\bigoplus_{S,c}U_S^c(E)\otimes B_I[c],\qquad B_I=\mathbf Q[x_i:i\in I]/(x_i^2),\quad I=[n]\setminus S. V∗(XE​)=S,c⨁​USc​(E)⊗BI​[c],BI​=Q[xi​:i∈I]/(xi2​),I=[n]∖S.

Under u⊗xT↦(∏i∈Tai)jTuu\otimes x_T\mapsto (\prod_{i\in T}a_i)j_Tuu⊗xT​↦(∏i∈T​ai​)jT​u, multiplication by ℓ\ellℓ is multiplication by EI=∑i∈IxiE_I=\sum_{i\in I}x_iEI​=∑i∈I​xi​. The square-zero algebra has the standard Lefschetz strings, so EIm−2t:BIt→BIm−tE_I^{m-2t}:B_I^t\to B_I^{m-t}EIm−2t​:BIt​→BIm−t​ is an isomorphism for 0≤t≤m/20\le t\le m/20≤t≤m/2.

If k=∣S∣=2c−1k=|S|=2c-1k=∣S∣=2c−1, the arithmetic exponent is n+1−2r=m−2tn+1-2r=m-2tn+1−2r=m−2t, with t=r−ct=r-ct=r−c. Thus central blocks satisfy the desired isomorphisms. Conversely, for a nonzero block put d=k+1−2cd=k+1-2cd=k+1−2c. If d>0d>0d>0, choose r=cr=cr=c: the power m+dm+dm+d kills USc⊗1U_S^c\otimes1USc​⊗1, contradicting injectivity. If d<0d<0d<0, choose r=k+1−cr=k+1-cr=k+1−c: the source has polynomial degree d<0d<0d<0, whereas the target contains USc⊗xIU_S^c\otimes x_IUSc​⊗xI​, contradicting surjectivity. Hence all surviving blocks are central.
