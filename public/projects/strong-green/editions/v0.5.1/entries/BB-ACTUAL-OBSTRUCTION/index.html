A Chow-invariant actual Bott–Chern obstruction

The curvature of a model Green pair is proposed to depend only on its generic Chow class.

v0.5.1 · Local Green forms

Statement

Set

HBC,actr,r(X)={ω∈Br,r(Xan):d′ω=d′′ω=0}DBr−1,r−1(Xan). H^{r,r}_{\mathrm{BC,act}}(X)= \frac{\{\omega\in\mathcal B^{r,r}(X^{\mathrm{an}}):d'\omega=d''\omega=0\}} {D\mathcal B^{r-1,r-1}(X^{\mathrm{an}})}. HBC,actr,r​(X)=DBr−1,r−1(Xan){ω∈Br,r(Xan):d′ω=d′′ω=0}​.

The proposed construction gives a rational-linear map

oX,Kr:CH⁡r(X)Q⟶HBC,actr,r(X) \mathfrak o^r_{X,K}:\operatorname{CH}^r(X)_{\mathbf Q} \longrightarrow H^{r,r}_{\mathrm{BC,act}}(X) oX,Kr​:CHr(X)Q​⟶HBC,actr,r​(X)

represented by degree-rrr model Chern-character forms. It is invariant under rational equivalence and functorial for the genuine analytic pullbacks specified in (A1), including rational fibre maps.

Motivation

The Bott–Chern target and the separately selected residual-period targets in the historical programme are different constructions. Identifying them requires the recorded comparison hypotheses.

Draft proof route

Generic acyclic model complexes yield global actual primitives. This handles generic K0K_0K0​-relations. A rational Adams projector isolates degree rrr, so model characters with the same generic codimension-rrr Chow class differ by DDD of a global actual form. Their classes therefore define the proposed map.
